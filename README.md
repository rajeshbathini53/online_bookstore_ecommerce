# 📚 Online Book Store E-Commerce

An online bookstore web application built using the **MERN Stack** that allows users to explore, search, and purchase books easily. The platform supports both customers and administrators, offering a smooth and secure shopping experience.


## 🚀 Features

### 🛒 For Customers
- Browse and search for books by category, author, or title  
- Add books to cart and place orders  
- User authentication (Sign up / Login with JWT)  
- View order history and book details  
- Responsive and mobile-friendly UI  

### ⚙️ For Admin
- Add, update, and delete book listings  
- Manage users and orders  
- Dashboard for sales overview  

## 🛠️ Tech Stack

Technology Used 
|-------|------------------|
| **Frontend** | React.js, HTML5, CSS3, Bootstrap |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB |
| **Authentication** | JSON Web Token (JWT) |
| **Hosting (optional)** | Render / Vercel / MongoDB Atlas |


## ⚙️ Installation & Setup

Follow these steps to run the project locally 

# Clone this repository
git clone https://github.com/rajeshbathini53/online_bookstore_ecommerce.git

# Navigate into the project folder
cd online_bookstore_ecommerce

# Install backend dependencies
npm install

# (If you have a frontend folder, navigate into it and install dependencies)
cd client
npm install

# Go back and start the backend server
cd ..
npm start
